# eigen G2：native A/B 与 riscv64 交叉基线（2026-11-13）

- 上游：`libeigen/eigen` @ `1cf2f01`，header-only
- 构建：不经编译，`pkg-build.sh` 只把 `Eigen/` 与 `unsupported/` 拷进 `<build>/pkg/prefix/include`
- 探针：`test/pkg_eigen.cpp`

| 路径 | native | riscv64 (rv64gc) |
|---|---|---|
| 整数 64×64 `A*B`（逐位精确） | `fnv=b6934bd0094dc25a` | 同左 |
| 双精度 128×128 `X*Xᵀ`（量化 1e-6） | `fnv=72dccc2fcdc7d3ba`，`max_rel=2.3e-13` | `fnv=72dccc2fcdc7d3ba`，`max_rel=1.9e-13` |

判据分成两条：**整数路径逐字节**（跨架构必须完全相同）；**浮点路径容差**（先量化到 1e-6 再取哈希，
真实误差对 long double 参考单独打印，阈值 1e-12）。这样不会因为末位舍入把结论搅成“假红”。
